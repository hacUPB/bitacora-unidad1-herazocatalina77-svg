# ¿Qué entendemos por shader?
Shader es un segmento de código y/o texto el cual configura diferentes elementos de los gráficos 
# ¿Qué se necesita para utilizar un shader en OpenGL?
Se necesita ya sea un x,y,z o un rgb o un uv para definir el tipo de shader
Se necesita un VBO para conocer que valores tiene el shader (si tiene solo posición, o si también tiene color u offset)
